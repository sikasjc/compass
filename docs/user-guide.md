# Compass 使用说明

Compass 当前覆盖关注标的、日线行情、策略管理和回测。界面包含五个页面：标的池、行情数据、策略实验室、策略回测、设置。

## 1. 标的池

系统只维护一个“关注标的”池。

1. 打开“标的池”。
2. 先选择上证或深证市场，再输入六位代码；支持换行、逗号或空格分隔。
3. 也可以点击“大盘核心”“全市场宽基”“成长科技”“红利风格”快捷按钮追加常用指数；有对应指数时预设不再优先使用 ETF。
4. 核对代码后的灰色中文名称，点击“保存关注标的”。

如果旧版本中存在多个已启用标的池，页面会先合并显示其中的标的。首次保存后保留一个主池，旧池仅停用，不删除历史记录。

## 2. 行情数据

打开“行情数据”，可以：

- 查看当前已保存标的数量、最新日期和数据版本；
- 预览日线价格、成交量和最近五条记录；
- 选择近 2 年、近 5 年、近 10 年或自定义区间；
- 执行全部增量同步、只同步缺失标的，或者重试单个标的；
- 查看每次任务的来源、区间、时间、标的级获取进度、成功状态与错误码；
- 分页浏览任务历史，并清除已结束的历史记录；
- 清理单个标的或全部标的的本地行情数据（确认后执行）。

页面会区分两种情况：

- “现有数据区间内交易日连续”：已经保存的起止日期之间没有断档；
- “较早历史未覆盖”：标的在当前数据首日以前还有目标交易日未取得，不代表现有区间内部缺数据。

同步成功后，新任务会显示新获取行数、复用本地可信数据行数，以及所选区间是否仍有未覆盖交易日。

## 3. 策略实验室与策略回测

“策略实验室”负责创建、复制、版本化和停用策略定义，并说明每种策略的原理、适用场景和风险。

“策略回测”页面提供一条可人工核对、可组合的基础回测链路：

- 选择策略信号指数后自动推荐对应 ETF，也可以手动更换实际交易 ETF；
- 单独选择用于比较的指数或其他基准；
- 设置回测区间、初始资金、佣金、最低佣金和滑点；
- 选择“下一交易日开盘”或“下一交易日收盘”成交；
- 比较买入持有和双均线趋势策略；
- 查看收益、最大回撤、夏普率、费用、净值曲线和逐笔成交记录。

所有策略信号都在当日收盘后产生，最早在下一交易日成交。指数用于产生信号和比较收益，实际订单与持仓始终使用 ETF；推荐 ETF 尚无行情时需要先加入标的池并同步。

## 4. 数据源

默认优先使用腾讯证券历史行情。当前实测它对常用沪深指数与 ETF 日线更稳定，指数通常也拥有更长的可回测历史。

腾讯证券当前主要用于沪深指数和 ETF；股票行情虽然可以读取，但缺少可核验的历史 ST/上市初期交易规则时不会替代已有可信数据。系统按最多两年一个请求分段获取，并把腾讯的成交量“手”和成交额“万元”统一换算为“股”和“元”。东方财富（通过 AKShare 适配）和 BaoStock 作为后续备用来源或交叉核对。不同来源的可用历史长度可能不同；页面中的“实际来源”记录最终写入该标的数据源。

## 5. 设置

“设置”页面只保留与行情功能有关的选项：

- 调整行情提供方优先级；
- 查看提供方是否可用；
- 设置东方财富、腾讯证券等 HTTP 行情源的标的级并发请求数（1～8）；
- 设置单次行情网络请求/连接的超时时间（3～60 秒，默认 5 秒；慢速网络建议 10～15 秒）；
- 设置直连、系统代理或自定义代理，并分别测试代理、东方财富、腾讯证券和 BaoStock；
- 设置本地日志级别；
- 点击“查看日志”，按级别或关键词检查最近的应用日志与行情请求诊断。东方财富和腾讯证券会记录 HTTP 接口地址、操作和脱敏响应摘要；BaoStock 会记录 TCP 主机端口、操作与返回错误码。新日志从功能启用后开始记录，不会补录旧任务的网络响应。

BaoStock 使用会话式接口，为保证稳定性固定按 1 个请求执行，不受 HTTP 行情源并发数影响。

## 6. 数据文件

应用只在本地运行。同步会先完整写入并校验新行情，成功后替换当前数据并清理旧版本；失败时仍保留原有可用数据。每个标的只保存一份最新行情，当前数据的完整校验码可在行情页按需展开。
